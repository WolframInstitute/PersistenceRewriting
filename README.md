# PersistenceRewriting

Track elementary multiway entities (EMEs) through rewriting system evolutions, computing lifetimes and decay statistics.

Wolfram Language paclet `WolframInstitute/PersistenceRewriting` (Wolfram Language 14.3+), depending on
`WolframInstitute/Hypergraph`, `WolframInstitute/InfraCausality` and `Wolfram/Multicomputation`.
